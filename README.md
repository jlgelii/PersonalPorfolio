# Jeffrey Geli — Developer Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

No build tools or dependencies are required. Google Fonts are loaded online; the page still works with system fallbacks if they are unavailable.

## Before publishing
- Confirm that the phone number and location are still the contact details you want public.
- Add links to your LinkedIn profile and any live demos or repositories you want to feature.
- Add 2–4 real project case studies (problem, your role, stack, solution, outcome). The current page intentionally does not invent project details.
- Consider adding a PDF resume download after choosing the version you want public.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation, current year, and back-to-top behavior
- `assets/jeffrey-geli-profile.jpg` — profile portrait used in the About section
